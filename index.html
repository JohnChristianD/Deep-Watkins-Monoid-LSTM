Deep Watkins RNN / Q8.24

Recurrent value learning, made explicit.

Deep Watkins RNN is an Agda-first reinforcement-learning prototype built around a Q8.24 recurrent feature cell and two live dueling IQN32 critics.

Prototype status: numerical and end-to-end validation remain open.

MODEL SPECIFICATIONQ8.24 / IQN32

Network contract

Recurrent state
One scalar hidden feature
Critics
Two live dueling IQN32 networks
Randomness
Quantile fractions and noise supplied by the host
Update rate
One critic update per transition
target = reward + gamma * Q_peer

Terminal transitions use reward only. The peer evaluates the active critic's selected action.

One state, two critics, one update.

The implementation keeps recurrent differentiation, distributional value estimation, and transition ownership explicit in the Agda source.

Feature cell
Quantmoid4 bounds the input feature. A hard-sigmoid gate mixes the previous hidden value with a ReLU candidate.
Value model
Each critic has a noisy value head and non-empty per-action noisy advantage heads. Cosine embeddings remain the IQN quantile features.
Distributional loss
Thirty-two current quantiles and thirty-two target quantiles form a 32-by-32 quantile-Huber objective.
Optimizer
Each learned parameter carries diagonal IDBD state, with projected Q8.24 log step sizes and a separately configured L2 gradient term.

A single aligned SARSA transition.

The active critic chooses the next action; its peer evaluates that same action. The active critic alone receives the update.

  1. Select

    The active critic evaluates the next state and selects one action using host-provided noise and quantile fractions.

  2. Evaluate

    The peer critic estimates the selected action's quantiles. It does not choose a second action.

  3. Update

    The active critic receives one quantile-Huber update, then the active side alternates for the next transition.

Transition contract. The pending decision carries the selected action, recurrent cache, current quantile fractions, and peer-noise sample. Ordinary Agda function types still do not prove affine use.
